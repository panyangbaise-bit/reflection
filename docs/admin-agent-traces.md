# Agent 轨迹与用户筛选

管理后台按用户和任务浏览 Agent 轨迹，任务列表包括状态、用户、触发类型、模型和 token；时间线按模型轮次组织工具调用，显示时间、耗时、参数、结构摘要和错误。用户选择支持 UUID 和 Sandbox 测试账户名，默认用户每页 100 条、任务每页 30 条。用户苹果标识不返回到后台筛选列表。

默认只保存脱敏参数和结构摘要。`PA_AGENT_TRACE_CAPTURE_CONTENT=true` 可为新任务保存完整模型输入/输出及工具输入/输出，供 owner/operations 排查；配置要求 `PA_AI_DISCLOSURE_VERSION` 至少为 3，现有旧授权需要重新确认。iOS 授权页根据服务器配置展示内容记录说明。完整内容可能包含持仓、对话和其他私人数据；访问继续经过管理员角色校验和审计。嵌套字段名包含常见凭据或模型推理时被屏蔽，不记录模型内部推理。单条超过 100,000 字符时保存截断预览并标识，不能当作完整内容。默认保留 30 天，账户删除清除轨迹；之前没有记录的内容无法补回。

本设置仅用于隔离测试环境；旧版客户端不会展示新增披露说明，上线前必须确保所有客户端能展示当前披露内容并要求重新授权。管理界面通过本地 SSH 隧道连接，不公开 Admin API。
