# 跨市场标的搜索

## 2026-11-03 修复

旧版美股目录依赖 `stock_us_spot_em()`，该报价列表在测试服务器持续断连，美股目录因此为空。未命中时，任一市场的同步时间缺失都会返回 `catalog_partial / 503`；同步时间仅存在可被淘汰的 Redis 中。这造成了 QQQ 搜索失败，并使普通未命中看起来像整体服务故障。

现在目录、实时查询和报价分离：

- 美股和美股 ETF 使用 Nasdaq Trader 官方 `nasdaqlisted.txt` / `otherlisted.txt`。校验表头、文件结束标记和最小行数，排除 Test Issue，按来源 ETF 标志分类；两个文件都成功后才更新。不会猜测东方财富交易所 ID。
- A 股和港股继续使用已验证的新浪目录。场内 ETF、LOF、封闭式基金分别同步；LOF / REIT 等非 ETF 场内基金使用 `listed_fund`，与相同代码的场外 `fund` 保持不同标的 ID。
- 场外公募基金使用天天基金全目录，不再按“货币 / 理财”类型从搜索结果过滤。目录存在不表示该产品一定能获取单位净值，万份收益或七日年化不会当作净值。
- 代码精确命中直接查询数据库。名称、拼音及未命中的代码可通过东方财富 suggest 接口补充发现，并保存中文名 / 拼音别名。来源市场、证券类型、代码格式经过校验，不接受任意供应商返回的市场。单次网络超时 2.5 秒，结果缓存 15 分钟，共享每分钟 60 次上游查询额度。
- 数据源查询失败保留已有结果，不清空目录、不制造标的。全量同步仍由独立 collector 负责，API 不再拉取巨大的全市场报价列表。
- 每类目录的成功时间、尝试时间、处理行数和错误码写入 PostgreSQL `catalog_sync_states`。Redis 清理不再丢失同步状态。失败后 5 分钟重试、成功后按 `PA_CATALOG_SYNC_HOURS`（默认 24 小时）更新。
- 搜索支持大小写、全角字符、短港股代码及 `QQQ.US` / `700.HK` / `600519.SH` 等写法。未命中不再因其他市场同步失败返回 503；完全空库仍明确提示初始化中。

`PA_CATALOG_LIVE_SEARCH_ENABLED=false` 可关闭按需上游查询，本地目录搜索继续可用。按需查询只更新已有自动目录的搜索别名，不覆盖其标的 ID、报价源或手工配置。

## 报价与录入

目录接口只提供身份。美股新增目录使用独立的新浪日线收盘价适配，保留纽约时区和来源日期，标记 `close`，不标为实时。无行情时仍可搜索、选中、填写数量和成本创建持仓；不使用成本冒充市值。未填成本且没有可用报价时，继续要求用户提供成本。

iOS 结果行标明 A 股、港股、美股、ETF、场内基金或场外基金，避免同代码的场内外基金混淆。

覆盖目标是来源可取得的沪深北 A 股、港股、美股交易所上市证券及场内外公募基金。私募、未上市产品、全部 OTC 产品以及新上市产品在来源发布前不作全覆盖承诺。目录可搜索也不代表所有标的都具有实时行情。

## 验证与运维

`make test` 包含官方目录解析、ETF 分类、截断响应拒绝、同代码双场景基金、缓存清空和刷新失败保留目录、中文别名发现、来源超时降级、七类标的搜索后创建持仓等回归测试。

手动全量同步：`python -m portfolio_backend.services.catalog`。可通过重复 `--kind` 参数选择 `cn-stock`、`cn-etf`、`hk-stock`、`cn-fund`、`us-stock`、`cn-lof`、`cn-closed-fund`。每类独立记录结果；任何一次同步失败都不删除上次可用目录。

官方目录说明：[Nasdaq Symbol Directory Definitions](https://www.nasdaqtrader.com/Trader.aspx?id=SymbolDirDefs)。场内基金接口来源：[AKShare fund_etf_sina.py](https://github.com/akfamily/akshare/blob/main/akshare/fund/fund_etf_sina.py)。本轮实际部署及处理数量见部署记录。
